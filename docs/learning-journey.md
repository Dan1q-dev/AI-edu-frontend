# Путь обучения и встроенный тьютор

Регистрация создаёт аккаунт; выбор траектории вынесен следующим шагом в личный кабинет. Для курса с certificate_enabled главная страница показывает модули в порядке прохождения, материалы, отдельный итоговый тест каждого модуля и получение сертификата.

Все условия доступа и выдачи документа проверяет backend. Часы и число модулей берутся из его настроек; последняя схема проекта: две траектории, три модуля и 72 часа. Сертификат скачивается как PDF, QR ведёт на публичную проверку по UUID без раскрытия email и профиля.

Тьютор встроен в страницу лекции и практической работы. В практике подсказки относятся к заданию, в лекции - к тексту лекции. На телефоне используется панель внутри текущего материала, без отдельного маршрута. При переходе меняется context_id и прекращается прежняя генерация. В тестах тьютора нет.

Для выкладки требуется backend с API journey/certificate и поддержкой практики в tutor/context.py. Сначала обновляется backend и выполняется миграция, затем frontend. Настройка программы включается в редакторе курса. Неполные учебные материалы не заменяются демонстрационным содержимым и не публикуются автоматически.
